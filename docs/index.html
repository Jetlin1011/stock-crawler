Install on your phone

iPhone / iPad: open this page in Safari → tap Share (□↑) → Add to Home Screen → Add. It then opens full-screen like a normal app.

Android: Chrome menu ⋮ → Install app (or "Add to Home screen").

Phone notifications

Get a push notification each evening when the new scan is ready (no Telegram needed). On iPhone this works only after installing to the Home Screen (iOS 16.4 or newer), and you must open the installed app to switch it on.

Last step (one time per device): copy this code and save it in GitHub → your repo → Settings → Secrets and variables → Actions → secret PUSH_SUBSCRIPTIONS. For more than one device, put each code on its own line in that same secret.

Refreshing

New results arrive once a day after market close (~6 PM IST). The app checks for them automatically whenever you open it, when you come back to it, and every 15 minutes while it's open. You can also tap ⟳.

Signals come from historical price patterns and headline keywords. They are not investment advice — you decide every trade, and you should always use a stop-loss.
